# LDL-C Machine Learning Estimation

Machine learning models for estimating LDL cholesterol (LDL-C) from routine
laboratory panels, as an alternative to fixed equations traditionally used
when direct measurement is unavailable.

## Status
- Active research; currently in IRB review
- Manuscript prepared for submission to peer-reviewed journals

## Methods & Stack
- Python, Pandas, NumPy for data preprocessing
- Scikit-learn for regression modeling and evaluation
- Matplotlib / Seaborn for analysis and visualization

## Motivation
Accurate LDL-C estimation matters for cardiovascular risk assessment.
This project evaluates whether learned models can outperform standard
estimation equations across patient subgroups, with careful attention to
where models should defer rather than predict.

*Data and results will not be published here until IRB and journal review
are complete.*
